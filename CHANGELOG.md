# Changelog

### Added

- WPF-приложение LeadGen v6 на .NET 10
- Дашборд со статистикой и графиками
- Обработка лидов Webbee AI (JSON/TSV/CSV) с экспортом Bitrix CSV

- Менеджер городов и конфигурации (`config.json`)

- 44 unit-теста, CI на GitHub Actions
